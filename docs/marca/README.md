## Paleta (slots de Kadence)

| Slot | Hex | Uso | Contraste |
|---|---|---|---|
| palette1 | `#C2410C` | Botones, enlaces, precios | blanco encima 5,2:1 |
| palette2 | `#9A3412` | Hover de botones | blanco encima 7,3:1 |
| palette3 | `#1C1917` | Títulos | 16,5:1 sobre crema |
| palette4 | `#292524` | Texto principal | — |
| palette5 | `#57534E` | Texto secundario | 7,2:1 sobre crema |
| palette6 | `#78716C` | Bordes de campos | ≥ 3:1 |
| palette7 | `#FFEDD5` | Fondo de cabeceras de página, etiquetas | — |
| palette8 | `#FFF7ED` | Fondo crema | — |
| palette9 | `#FFFFFF` | Tarjetas, fondo de productos | — |

Ningún verde en la marca: el verde queda reservado para WhatsApp, así el botón destaca solo.
No usar `#F97316` (naranja vivo) con texto blanco: 2,8:1, no pasa WCAG.

## Tipografía

- Títulos: **Fredoka** 600 (redondeada, amigable).
- Texto: **Nunito** 400/700, base 16 px.
